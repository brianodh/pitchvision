# PitchVision ⚽

### AI-Powered Football Event Spotting & Match Intelligence

PitchVision is a football video-analysis system developed for **PARC 2026 AI League**. The system uses computer vision and temporal machine learning to analyze football match footage and identify important football events.

The current MVP allows a user to:

* Upload a football match video
* Provide a YouTube match-video URL
* Process the video using the trained PitchVision model
* Detect football events automatically
* Generate a searchable event timeline
* Filter detected events by event type
* Review event confidence scores
* Export detected events as JSON or CSV

# 3. Requirements

### Hardware

The application can run on CPU, although video feature extraction and inference may be significantly faster with a CUDA-compatible GPU.

Recommended:

* 8 GB+ RAM
* 10 GB+ available storage
* NVIDIA GPU with CUDA support recommended for faster inference

The application automatically selects CUDA when it is available and otherwise falls back to CPU.

### Software

Required:

* Python 3.11+ recommended
* Git
* FFmpeg
* Streamlit
* PyTorch
* TorchVision
* OpenCV
* NumPy
* yt-dlp

# 12. Configure Analysis

The sidebar provides the following options.

### Model Checkpoint

Default:

```text
model/results/checkpoints/v3_ckpt_W7_seed0.pt
```

### Detection Threshold

The detection threshold controls the minimum confidence score required for an event to appear in the generated timeline.

Default:

```text
0.50
```

### Maximum Duration

This controls how much of the video should be processed.

```text
0 = entire video
```

For testing, a shorter duration can be used.

For example:

```text
120
```

will process approximately the first two minutes.

This is useful when testing the system before processing an entire match.

# 18. Command-Line Inference

The underlying inference engine can also be used without Streamlit.

Example:

```bash
python model/scripts/spot_video.py \
    --video "/path/to/match.mp4" \
    --ckpt "model/results/checkpoints/v3_ckpt_W7_seed0.pt" \
    --out spot_output
```

Optional parameters include:

```text
--max_seconds
--threshold
--labels
```

Example:

```bash
python model/scripts/spot_video.py \
```

# 20. Troubleshooting

## `ModuleNotFoundError: No module named 'scripts'`

Make sure:

```text
model/scripts/__init__.py
```

exists.

Create it if necessary:

```bash
touch model/scripts/__init__.py
```

Then verify the import:

```bash
python -c "import sys; sys.path.insert(0, 'model'); from scripts.spot_video import run_inference; print('run_inference imported successfully')"
```

---

## `Model checkpoint not found`

Verify the checkpoint:

```bash
ls -lh model/results/checkpoints/v3_ckpt_W7_seed0.pt
```

The correct default checkpoint is:

```text
model/results/checkpoints/v3_ckpt_W7_seed0.pt
```

Do not use the old:

```text
model/results_v2/ckpt_W7_seed0.pt
```

path.

---

## Streamlit cannot start

Check that the virtual environment is active:

```bash
which python
```

Then verify Streamlit:

```bash
streamlit --version
```

If necessary:

```bash
pip install streamlit
```

---

## YouTube download fails

Verify `yt-dlp`:

```bash
yt-dlp --version
```

The Python package can also be checked with:

```bash
python -c "import yt_dlp; print(yt_dlp.version.__version__)"
```

Make sure FFmpeg is installed:

```bash
ffmpeg -version
```

---

## Inference is very slow

PitchVision automatically uses CUDA when available.

Check:

```bash
python -c "import torch; print('CUDA available:', torch.cuda.is_available()); print('Device:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

CPU inference can take considerably longer for full-length football matches.

For testing, use the maximum-duration option:

```text
Maximum duration: 120
```

# 22. Important Development Notes

PitchVision's trained model and application are separate components.

The Streamlit interface does **not** retrain the model.

The application loads an existing checkpoint and performs inference on the supplied video.

The current application uses the W7 v3 checkpoint:

```text
v3_ckpt_W7_seed0.pt
```

The W15 and W31 checkpoints are also available for experimentation:

```text
v3_ckpt_W15_seed0.pt
v3_ckpt_W31_seed0.pt
```

The current MVP should preserve the established model architecture and trained checkpoints unless the AI/model team explicitly decides otherwise.
