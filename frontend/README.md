# frontend/

**Prototype work, not part of the PARC qualifier submission.**

Planned: an upload-and-view interface for the event timeline produced by the backend (searchable list, filter by event
type). It should depend only on the backend's JSON response, never on `model/` directly, so it can be developed against
a mocked response without a GPU or the dataset.

How to contribute: create a branch (`feature/frontend-...`), add code here, and replace this paragraph with the commands
to install and run it.
